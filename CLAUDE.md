# Collaborator Rules
1. Create code that is maintainable, readable, and consistent with the rest of the codebase.
2. Write code that is well-tested
3. For code implementation, you can open requirements folder and understand how things going.But if I tell you to make change outside of this folder, you can do that too.
4. When I ask something that I do not understand, Explain me and ask me to continue.Suggest code implementation after continuing, not before
5. If I suggest something and it is not correct, you can explain to me the error that could have happened based on examples.
6. Try not to use too many words and sentences to explain me.Try to keep it simple and clear as possible.
7. During testing controller logic we need also to test what data have stored in db. Moreover, it would be better for this to test the other columns except the id column, to make test more readable and useful.
8. On frontend, ensure that the UI is responsive and friendly for users. Try to use relative metrics such as % vh, etc instead of px. Also make the UI suitable and clearly visible for all screen sizes.Tip, inside a dark box we need light text for better readability, and vice versa.Also use your knowledge about human eye for color contrast and visual hierarchy to enhance user experience.
